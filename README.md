# LIVBRID HQ

LIVBRID's brand workspace (product working name: My Brand Team). One workspace per brand,
where the team and Claude keep the plan, guidelines, channels and content in one place.

## Run it locally

1. `cp .env.example .env.local` and fill in the two public Supabase values.
2. `npm install`
3. `npm run dev` and open http://localhost:3000

Project rules for people and for Claude are in `CLAUDE.md`.
